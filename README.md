## 关于我

我是 Bryce，一名关注数学建模、科研自动化和大模型应用的开发者，常驻合肥。我的主要兴趣是把复杂问题拆成可计算、可复核、可交付的工程流程：从数据下载、清洗、建模、可视化，到论文生成、质量审查和交付打包。

目前我在打磨 `ModelArk / 数模方舟`，希望让数学建模竞赛中的选题分析、代码求解、图表生成、论文写作和质量门禁形成一个更稳定的闭环。

## 工作方式

- 先把问题拆成可验证的小目标，再决定模型、算法和代码结构。
- 让结果尽量来自脚本和日志，而不是手工搬运。
- 对图表、表格和论文文字保持审稿人视角：数值要可追溯，结论要有证据。
- 偏好能够长期复用的工具，而不是一次性的演示脚本。
